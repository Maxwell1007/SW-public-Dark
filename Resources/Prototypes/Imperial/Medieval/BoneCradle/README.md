# Костяная колыбель

На релизной карте разместите `MedievalBoneCradleSpawnMarker` минимум по одному в каждом из девяти секторов. Несколько маркеров в секторе дают случайный выбор места появления одной колыбели.

Сектор читается из `CultMapBlocker.sector` родительского грида, как у Spellward: `sector1`–`sector9`. Вручную настраивать сектор или календарный идентификатор у маркера не нужно. Размещайте маркеры на свободных площадках с учётом используемого спрайта пьедестала размером 3 × 3 тайла. Маркеры сохраняются после исчезновения колыбели и используются повторно.

Правило `MedievalBoneCradleRule` подключено к режиму `MedievalSkeletron`. По умолчанию события назначаются на дни 2, 4, 6, 8, 10 и 12. Сектора с маркерами перемешиваются и используются без повторов до исчерпания списка. Сектора без маркеров исключаются из расписания с предупреждением в серверном логе.

Расписание настраивается в `bone_cradle.yml`: `firstDay` задаёт первый день, `dayInterval` — интервал, `isNight` переключает расписание на ночи. `events` связывает девять календарных событий с секторами.

Колыбель существует 600 секунд игрового времени. Попытка запуска другого события при существующей колыбели завершается без нового спавна и записывает ошибку в серверный лог. Прямое создание второй сущности также отклоняется: второй экземпляр ставится в очередь удаления, первый сохраняется. Пропущенное событие не переносится на более позднее время.

В публичной копии календарь использует цикл в 24 минуты: 12 минут дня и 12 минут ночи. Если релизная система времени отправляет сигналы смены стадий `DayTime`, календарь автоматически начинает следовать им. Срок жизни колыбели в обоих случаях отсчитывается отдельно.
